# AGENTS

Guidance for agents in this repository.

## Repository purpose

Reusable Agent Skills and related review/reference material.

## Change guidelines

- Keep skill behavior, constraints, and trigger boundaries explicit.
- Treat changes to `SKILL.md` files and closely related skill assets as behavior/instruction changes, not mere documentation edits.
- Preserve required frontmatter and markdown structure in skill files unless the user asks otherwise.

## Commits

- Use conventional commit messages.
- Do **not** use `docs:` for changes to `SKILL.md` files or sibling files that affect agent behavior, instructions, review criteria, or triggering.
- Use `feat:`, `fix:`, `refactor:`, or `chore:` when they better match the change.

## README updates

- Keep skill descriptions concise.
- Ensure added or updated skill entries match the skill's current purpose.
