# Bisar Skills

A collection of reusable Agent Skills (SKILL.md) for AI coding assistants.

## My skills

| Skill | Description |
|-------|-------------|
| `answer-options` | Ask one question at a time with concise numbered options so the user can reply by number |
| `optimize-context-docs` | Reduce token usage in LLM context documents while preserving behavior and guardrails |
| `review-skill` | Review and improve SKILL.md files using local reference docs adapted from agentskills.io best practices |
